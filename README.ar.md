# بوت الحظر الجماعي

[English](README.md) · **العربية**

بوت تيليجرام يحظر الحساب من كل مجموعة وقناة تشرف عليها، بعد تأكيد واحد.

أضف البوت إلى محادثاتك مشرفًا، ثم احظر الشخص مرة واحدة: بالرد على رسالته، أو بإرسال رقم حسابه.
يحظره البوت في كل محادثة يراقبها، ويحذف ما ينشره، ويحظره من جديد إن انضم. ويوجّه تحذيرات للأعضاء،
ويحذف الرسائل التي تطابق قائمة عبارات ممنوعة، ويزيل إشعارات الانضمام والمغادرة والتثبيت التي تزحم المجموعة.

يعمل على منصة تيليجرام الخالية من الخوادم، فلا خادم تستضيفه. الشيفرة بلغة JavaScript وتُنشر بأمر واحد.
يكتب البوت رسائله بالإنجليزية بخط الأحرف الصغيرة الكبيرة (small caps).

## ما يفعله

- يحظر الحساب ويفك حظره في كل المحادثات المراقَبة دفعة واحدة، بما فيها محادثات لم ينضم إليها بعد
- يوجّه تحذيرات لكل مجموعة على حدة، وعند التحذير الثالث يسأل هل يحظر من هذه المجموعة أم من كل المحادثات
- يحتفظ بقائمة عبارات ممنوعة: الرسالة المطابقة تُحذف، والتكرار الثالث من الشخص نفسه يحظره
- يحذف رسائل الخدمة مثل الانضمام والمغادرة وتغيير الاسم والتثبيت
- يلغي تثبيت منشورات القنوات التي يثبّتها تيليجرام في مجموعة النقاش المرتبطة
- يتيح للمالك إضافة مشرفين بالصلاحيات نفسها، ويعرض قائمة بآخر المشكلات في `/errors`

## شغّل نسختك

تحتاج إلى Node.js بإصدار 22 أو أحدث، وبوت على منصة تيليجرام الخالية من الخوادم:

```bash
git clone https://github.com/Zaky1m/telegram-group-ban-bot.git
cd telegram-group-ban-bot
npm install
npx tgcloud login        # link the bot
npx tgcloud push         # deploy
npx tgcloud migrate      # create the tables on the first deploy
```

ثم أرسل `/start` إلى البوت. أول حساب يفعل ذلك يصبح المالك، فافعلها قبل أن تشارك البوت مع أحد.
[اقرأ دليل النشر](docs/deploy.ar.md)
